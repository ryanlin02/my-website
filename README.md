# 重車貸款業務行動工具箱 📱

> 專為重車貸款業務專員設計的專業行動端試算與開票輔助工具箱 (PWA)

## 🎯 專案簡介

本專案係集合多種實用貸款試算、支票開立排程、發票金額轉換與柴油折讓效益分析功能的行動網頁應用程式 (PWA)。採用現代化 PWA 技術，提供離線使用能力與原生 App 般順暢的操作體驗，特別針對手機直式螢幕優化，協助業務專員在展業洽談現場進行精準且高效的試算。

## ✨ 主要功能

### 🧮 貸款試算工具 (`pages/calculator.html`)
- 精確租賃與貸款期數、利率、本金、期繳金額動態連動計算
- 稅前/稅後利率、佣後利率、資金成本 Spread 與 NPV 獲利指標分析
- 內建自訂數字輸入器與歷史試算紀錄（含客戶備註功能）
- 自動存檔與防刷頁保護機制

### 🏦 支票試算工具 (`pages/check.html`)
- 分期與遞延支票開票日期排程自動推算
- 繳款金額、押票保證金與中文大寫金額即時轉換
- 內建民國曆月曆選擇器與開票歷史紀錄管理

### 🧾 發票金額轉換工具 (`pages/invoice.html`)
- 5% 營業稅含稅與未稅金額即時雙向反推
- 阿拉伯數字即時轉換為標準國字財務大寫格式
- 內建微型加稅計算器與發票歷史紀錄管理

### ⛽ 油資折讓試算工具 (`pages/gas.html`)
- 中油 (CPC) 與台塑 (Formosa) 快捷柴油單價設定
- 車隊每月油資、公升數與折扣節省金額（月/年）動態分析
- 內建即時油價查詢網頁

## 🛠️ 技術特色

- **PWA 支援**：支援離線快取與加入主畫面安裝
- **零退化防護**：全站 LocalStorage 數據結構與歷史紀錄備註 100% 完整保留
- **響應式 UI**：暗黑專業主題，適配各種手機螢幕

```
│   ├── check.html     # 支票試算工具

│   └── gas.html       # 油資折讓試算工具

```
